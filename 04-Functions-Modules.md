# Задание 1: Создать модуль для работы со списком клиентов СТО

Создать собственный модуль **`garage_utils.py`**, содержащий функции для работы со списком клиентов СТО 

## Формат хранения клиента

Каждый клиент хранится в виде списка:

```
[id, имя, марка, год выпуска, сумма обслуживания]
```

Основная программа (`main.py`) должна импортировать этот модуль и использовать его функции.

# Функции, которые должны быть реализованы в модуле `garage_utils.py`

### 1. `show_all(clients)` — выводит всех клиентов в удобном формате.

### 2. `filter_by_brand(clients, brand)` — возвращает список клиентов указанной марки автомобиля (с использованием модуля re).

### 3. `add_service_cost(clients, index, amount)` — добавляет сумму к стоимости обслуживания клиента по номеру в списке.

### 4. `delete_by_index(clients, index)` — удаляет клиента по номеру в списке.

### 5*. `get_most_expensive(clients)` — возвращает клиента(ов) с максимальной стоимостью обслуживания.

### 6*. `delete_older_than(clients, years)` — удаляет всех клиентов, чьи машины старше указанного количества лет.

### 7*. `group_by_brand(clients)` — группирует клиентов по марке с использованием (itertools.groupby)
```
{
    "Audi": [name1, name2...],
    "BMW": [name1, name2...],
    "Toyota": [name1, name2...],
    ...
}
```

# Основная программа `main.py`

Основная программа должна:

- импортировать модуль `garage_utils`,
- реализовать меню:

1 — вывести всех клиентов  
2 — вывести клиентов только заданной марки автомобиля (марка вводится с клавиатуры)

* после выхода программа должна выдать кол-во удаленных клиентов за время своей текущей сессии (постарайтесь сделать через замыкания)

# Задание 2: Создать модуль для антиспам‑проверки сообщений

Создать собственный модуль **`spam_utils.py`**, содержащий функции для проверки сообщений перед публикацией.  
Перед публикацией каждое сообщение должно пройти проверку на наличие спам‑слов и подозрительных ссылок.  
Основная программа (`main.py`) должна импортировать этот модуль и использовать его функции.

## Список спам‑слов

```
["скидка", "бесплатно", "выигрыш", "кликни", "подпишись"]
```

Пользователь вводит текст сообщения.  
Программа должна выполнить две проверки.

---

## 1. Проверка на спам‑слова

Если количество спам‑слов больше 4 — сообщение **не публикуется**.  
Вывести: **"В тексте найдено большое количество спам слов"**

Если количество спам‑слов 4 или меньше — сообщение публикуется, но **с предупреждением**.  
Вывести: **"В тексте найдены спам слова"**

---

## 2. Проверка на ссылки

Сообщение считается подозрительным, если содержит `http://`, `https://` или `www.`.

Правила:

- Если есть ссылка и хотя бы одно спам‑слово — сообщение **не публикуется**.  
  Вывести: **"В тексте найдены ссылки и спам слова"**

- Если есть ссылка, но нет спам‑слов — сообщение публикуется, но **с предупреждением**.  
  Вывести: **"В тексте есть ссылки"**

---

Все предупреждения выводятся **до вывода текста сообщения**. Если все проверки пройдены — вывести исходный текст **без изменений**.

---

# 📦 Функции, которые должны быть реализованы в модуле **`spam_utils.py`**

### 1. `count_spam_words(message, spam_words)` — возвращает количество спам‑слов в сообщении.

### 2. `has_suspicious_links(message)` — проверяет, содержит ли сообщение подозрительные ссылки (`http://`, `https://`, `www.`).

### 3. `check_spam(message, spam_words)` — выполняет проверку на спам‑слова и возвращает текст предупреждения или `None`.

### 4*. `check_links(message, spam_count)` — выполняет проверку на ссылки и возвращает текст предупреждения или `None`.

### 5. `moderate_message(message, spam_words)` — объединяет все проверки и возвращает список предупреждений и итоговое решение о публикации.

### 6*. `add_publish_timestamp(message)` — добавляет к сообщению дату и время публикации с использованием модуля `datetime`.

---

# 📂 Основная программа `main.py`

Основная программа должна:

- импортировать модуль `spam_utils`,
- выполнить все проверки,
- вывести предупреждения (если есть),
- вывести итоговое сообщение (с датой публикации, если оно не заблокировано).
